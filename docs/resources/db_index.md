# mongodb_db_index (Resource)

Provides a MongoDB index on a collection.

## Example Usage

### Index

```terraform
resource "mongodb_db_index" "example_index" {
  db         = "my_database"
  collection = "example"
  name       = "my_index"
  keys {
    field = "field_name_to_index2"
    value = "-1"
  }
  keys {
    field = "field_name_to_index"
    value = "1"
  }
  # index options go last, in the order unique, sparse, expireAfterSeconds
  keys {
    field = "unique"
    value = "true"
  }
  keys {
    field = "sparse"
    value = "true"
  }
  keys {
    field = "expireAfterSeconds"
    value = "86400"
  }
  timeout = 30
}
```

### Partial index

```terraform
resource "mongodb_db_index" "partial_index" {
  db         = "my_database"
  collection = "example"
  name       = "my_partial_index"
  keys {
    field = "field_a"
    value = "1"
  }
  keys {
    field = "field_b"
    value = "1"
  }
  keys {
    field = "field_c"
    value = "1"
  }
  partial_filter_expression = jsonencode({
    "field_a" = { "$exists" = true }
  })
  timeout = 30
}
```

### Hidden index

```terraform
resource "mongodb_db_index" "hidden_index" {
  db         = "my_database"
  collection = "example"
  name       = "my_hidden_index"
  keys {
    field = "field_x"
    value = "1"
  }
  keys {
    field = "field_y"
    value = "1"
  }
  hidden  = true
  timeout = 30
}
```

## Schema

### Required

- `collection` (String) Collection to index. Changing it forces a new index.
- `db` (String) Database in which the target collection resides. Changing it forces a new index.

### Optional

- `hidden` (Boolean) Whether the index is [hidden](https://www.mongodb.com/docs/manual/core/index-hidden/) from the query planner (MongoDB 4.4+). Can be toggled in place without recreating the index, which helps evaluate whether an index is safe to drop. Defaults to `false`.
- `keys` (Block List) Index key specification: field and value pairs where `field` is the index key and `value` the index type for that field (`1` ascending, `-1` descending). The index options `unique = "true"`, `sparse = "true"` and `expireAfterSeconds = "<n>"` (TTL) are also expressed as `keys` entries; they are read back after the key fields in the order unique, sparse, expireAfterSeconds, so list them last in that order to avoid a plan diff. See [`createIndex`](https://www.mongodb.com/docs/manual/reference/method/db.collection.createIndex/). Changing it forces a new index. (see [below for nested schema](#nestedblock--keys))
- `name` (String) Index name. If omitted, MongoDB generates one. Changing it forces a new index.
- `partial_filter_expression` (String) JSON string with the `partialFilterExpression` of a [partial index](https://www.mongodb.com/docs/manual/core/index-partial/), e.g. `jsonencode({ field_a = { "$exists" = true } })`. Changing it forces a new index.
- `timeout` (Number) Timeout, in seconds, for the index creation operation. Defaults to `30`.

### Read-Only

- `id` (String) Base64-encoded ID of the index, in the format `db.collection.name`.

### Nested Schema for `keys`

Required:

- `field` (String) Field to index, or one of the index options `unique`, `sparse` or `expireAfterSeconds`.
- `value` (String) Index type for the field (`1` or `-1`), or the value of the index option.
