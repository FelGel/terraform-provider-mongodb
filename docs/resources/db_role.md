# mongodb_db_role (Resource)

Provides a custom MongoDB role. Use custom roles to define sets of privileges, optionally inheriting other roles, that can be granted to users.

## Example Usage

### Role with privileges

```terraform
resource "mongodb_db_role" "example_role" {
  name     = "role_name"
  database = "my_database"
  privilege {
    db         = "admin"
    collection = "*"
    actions    = ["collStats"]
  }
  privilege {
    db         = "my_database"
    collection = ""
    actions    = ["listCollections", "createCollection", "createIndex", "dropIndex", "insert", "remove", "renameCollectionSameDB", "update"]
  }
}
```

### Role inheriting another role

```terraform
resource "mongodb_db_role" "role" {
  database = "admin"
  name     = "new_role"
  privilege {
    db         = "admin"
    collection = ""
    actions    = ["collStats"]
  }
}

resource "mongodb_db_role" "role_2" {
  depends_on = [mongodb_db_role.role]
  database   = "admin"
  name       = "new_role3"

  inherited_role {
    role = mongodb_db_role.role.name
    db   = "admin"
  }
}
```

~> **IMPORTANT:** A role created in a specific database can only be inherited by other roles in the same database.

## Schema

### Required

- `name` (String) Name of the custom role. It can only contain letters, digits, underscores and dashes, and must not be the name of an existing custom role or of a [built-in role](https://www.mongodb.com/docs/manual/reference/built-in-roles/).

### Optional

- `authentication_restriction` (Block Set) Restricts the client and server addresses that users granted this role may connect from and to. Maps to MongoDB's role [`authenticationRestrictions`](https://www.mongodb.com/docs/manual/reference/method/db.createRole/#authentication-restrictions) (MongoDB 3.6+). May be repeated; a connection is allowed if it satisfies any one block. The configured value is kept in state as written; the provider does not read restrictions back from the server. (see [below for nested schema](#nestedblock--authentication_restriction))
- `database` (String) Database of the role. Defaults to `admin`. A role created in a specific database can only be inherited by other roles in the same database.
- `inherited_role` (Block Set) A role whose privileges this role inherits. (see [below for nested schema](#nestedblock--inherited_role))
- `privilege` (Block Set) A privilege granted by the role: a set of actions on a database or collection. (see [below for nested schema](#nestedblock--privilege))

### Read-Only

- `id` (String) Base64-encoded ID of the role, in the format `database.role`.
